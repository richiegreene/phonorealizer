# Phonorealizer

Inspired by Peter Ablinger's [_Phonorealism The Reproduction of "Phonographs" by Instruments_](https://ablinger.mur.at/phonorealism.html), Phonorealizer is a collection of analysis, composition, and performance tools aided to asist in spectral phonorealism (including hyperrealism, pseudorealism, surrealism, etc). 

## Modifier

The modifier area of these tools are designed as an open source FFT/DAW resembling Michael Klingbeil’s _Sinusoidal Partial Editing Analysis and Resynthesis [SPEAR](https://www.klingbeil.com/spear/)_. It contains all transormation procedures contained in SPEAR and adds them to allow the composer to more intuitively modify the rendered spectrum.

## Performer

These contain in progress tools to allow a performer feedback and video scrolling notation. Designed for phone interfaces on a given browser, UX differs _Performers_ and _Conductor_, where the conductor is responsible for starting the playback or all players parts simultaenously.
